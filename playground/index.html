lazyBoi playground

Test forms for the lazyBoi extension. Each page stresses a different kind of form. The right-hand panel shows the live form state, and counts submits (lazyBoi must never submit). Add ?harness to any page (or use the toggle in the top bar) to run lazyBoi in the page without installing the extension.

Basic

Text, email, phone, URL, number, date, textarea, limits, required.

Choices

Select, multi-select, radios, checkboxes, checkbox groups, datalist.

LinkedIn-like profile

Headline, About, repeated Experience and Project sections.

Job application

Multi-section, file upload, yes/no, essays.

Framework inputs

React-style controlled inputs that ignore plain value writes.

Dynamic / multi-step

Conditional fields, Next steps, "Add another".

Modal in shadow DOM

A LinkedIn-style "Add a role" dialog that opens late inside a shadow root, with fields that reveal more fields.

Rich text

contenteditable editors.

Iframe + shadow DOM

Fields inside a same-origin iframe and a web component.

Sensitive

Password, card, CVV, SSN: must be skipped.

Odd labels

aria-label, placeholder only, label after input, unlabeled.

Mock AI chat

A fake chat that answers with sample values, to test the widget's Paste and Copy buttons.
